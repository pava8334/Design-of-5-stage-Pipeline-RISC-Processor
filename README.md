# Design-of-5-stage-Pipeline-RISC-Processor
Design and implementation of an 8-bit RISC Processor featuring a 5-stage pipelined architecture (IF, ID, EX, MEM, WB) using Verilog HDL. Includes ALU, instruction decoder, register file, memory interface, simulation, synthesis, and FPGA implementation on the Basys 3 board using Xilinx Vivado
